# Tutor CRM

Локальная CRM одного частного преподавателя и его учеников. Основной язык интерфейса — русский. Проект реализуется как модульный монолит с Next.js, FastAPI, PostgreSQL и приватным S3-совместимым хранилищем.

## Текущий статус

Ветка `dev` содержит активную разработку. Ветка `prod` создаётся при первом полностью проверенном стабильном релизе. Функции из scope v2.0 в первую версию не входят.

## Быстрый запуск

Требуются Docker 28+ и Docker Compose 2.40+.

```bash
cp .env.example .env
docker compose -f infra/compose.dev.yaml up --build
```

После запуска:

- web: `http://localhost:3000`;
- API: `http://localhost:8000`;
- OpenAPI: `http://localhost:8000/docs`;
- локальный S3 endpoint: `http://localhost:4566`.

Проверка готовности API:

```bash
curl --fail http://localhost:8000/health/ready
```

Локальные проверки без контейнеров описаны в [docs/development.md](docs/development.md).

## Правила данных и денег

CRM хранит ФИО и класс ученика. Контакты ученика не входят в обязательную модель v1. Приглашение преподаватель передаёт вручную через выбранный канал. CRM не принимает и не переводит деньги: она только ведёт учёт начислений, заявлений ученика об оплате и ручных подтверждений преподавателя.
