# Этап: дизайн-токены и AppShell

Дата: 20 октября 2026 года. Ветка: `devRem`.

## Что реализовано

- Палитра приведена к утверждённым графитовым токенам, добавлены семантические токены отступов, радиусов и ширины навигации.
- Для авторизованных разделов добавлена единая оболочка `AppShell`: desktop sidebar 244 px, режим 72 px, верхняя панель и широкая рабочая область.
- Состояние свёрнутого sidebar сохраняется в `localStorage`; кнопка имеет доступные подпись и `aria-expanded`, у пунктов есть текущая страница и подсказки в свёрнутом режиме.
- Преподавательская и ученическая навигация построены только из существующих маршрутов. Глобальный поиск не добавлен, потому что общего backend-поиска в v1 нет.
- Выбор темы и выход перенесены в верхнюю панель. На телефоне используется нижняя навигация и компактная верхняя панель.
- Дублирующие наборы навигационных кнопок удалены с dashboard преподавателя и ученика; маршруты остались доступны через AppShell.
- Публичные и auth-страницы не оборачиваются в рабочую CRM-навигацию.

## Проверка

- `npm run lint` — успешно, 76 файлов.
- `npm test` — успешно, 4 файла / 6 тестов.
- `npm run build` — успешно, 22 маршрута.
- Авторизованный SSR-запрос `/teacher` через frontend вернул `200` и содержит доступную основную навигацию и заголовок кабинета.

Постраничная переработка dashboard, расписания и остальных модулей выполняется следующими отдельными этапами; эта фиксация меняет только общий каркас и не затрагивает бизнес-логику.
