# Отчёт по этапу: профиль ученика

Дата: 20 октября 2026 года  
Ветка: `devRem`

## Реализовано

- Профиль ученика приведён к утверждённому графитовому стилю.
- Добавлены вкладки «Обзор», «Занятия», «Домашние задания», «Программа» и «Финансы».
- Обзор показывает реальные показатели проведённых занятий, принятых ответов на ДЗ и задолженности.
- Вкладки занятий и финансов используют существующие данные v1 и сохраняют текущие бизнес-правила.
- Для преподавателя добавлено редактирование ФИО и класса ученика в боковой панели.
- Добавлена серверная сводка домашних заданий ученика со статусами «не задано», «ожидает проверки» и «принято».
- Раздел программы честно отмечен как находящийся в разработке: фиктивные показатели прогресса не добавлялись.
- Новые данные доступны только преподавателю и только для принадлежащих ему учеников.

## Ограничения этапа

Модель индивидуальной учебной программы отсутствует в v1. Её создание отложено, чтобы не добавлять функциональность v2.0 без отдельного согласования.
