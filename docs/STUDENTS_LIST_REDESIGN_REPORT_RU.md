# Этап: список учеников

Дата: 20 октября 2026 года. Ветка: `devRem`.

## Реализовано

- Список учеников перестроен в плотную таблицу по композиции `06_students_list_graphite.png`.
- Добавлены реальные сводные показатели: всего, активные, ожидающие активации и заблокированные аккаунты.
- Для каждого ученика backend возвращает ближайшее запланированное занятие и текущую задолженность по начислениям с учётом распределённых платежей.
- Добавлен серверный фильтр «есть задолженность / нет задолженности». Поиск, класс, статус, сортировка и пагинация сохранены.
- В таблице показаны только данные v1: ФИО, логин, класс, ближайшее занятие, задолженность и статус. Направление и вымышленный прогресс не добавлялись.
- Форма приглашения перенесена в компактное модальное окно. Ссылка активации по-прежнему показывается один раз и передаётся преподавателем вручную.
- На телефоне строки таблицы преобразуются в карточки, а форма приглашения открывается как нижняя панель.

## Финансовая логика

Задолженность рассчитывается как сумма `invoice.total` минус сумма `payment_allocations.amount` для начислений ученика. Расчёт не создаёт новых платежей, не меняет начисления и использует существующую модель подтверждённых распределений.

## Проверки

- Ruff и strict mypy — успешно.
- Полный `pytest` — успешно; добавлен интеграционный тест ближайшего занятия, задолженности, фильтра и сводных статусов.
- Biome — успешно; frontend unit-тесты — 5 файлов / 7 тестов.
- Production build Next.js — успешно, 22 маршрута.
